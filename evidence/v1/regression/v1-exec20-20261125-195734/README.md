# 阶段 4 · v1 扩采训练与 20 步回归

## 数据与训练

`prepare` 脚本的配置是 50 条成功训练示范、10 条成功验证示范。训练和验证的 LeRobot 数据集分别载于 `data/lerobot/v1/train` 和 `data/lerobot/v1/val`。脚本按回合分组，检查训练、验证和回归种子互不重叠。[采集与训练入口](../../../../scripts/run_panda_lift_v1.py)

训练原件记录了 RTX 4090 上的 `panda_act` 运行。共训练 3,000 步，batch size 32，4 个数据加载进程，训练种子 0。每 500 步做完整验证并存档。第 3000 步在已保存检查点中验证 L1 最低，为 0.1148771320。[训练配置](../../training/v1_3000_20261125_194654/run_config.json) · [原始训练指标](../../training/v1_3000_20261125_194654/metrics.csv)

## 20 步回归

在 `panda_sim` 中使用 NVIDIA EGL 和软重置，新旧权重复用 `1010–1019`，每回合最多 300 步，均固定每次执行 20 步。

| 权重 | 成功次数 |
| --- | ---: |
| 旧权重 | 2/10 |
| `v1` 的 `step_003000` | 5/10 |

`v1` 成功率为 50.0%，平均 188.5 步，平均裁剪步比例为 98.5%，平均动作请求耗时为 1.46 ms。同一批初态净多完成 3 个回合。[终端汇总转录](eval-summary.txt) · [v1 检查点路径](../../final/exec5-3100-3199-20261125-202416/checkpoint.txt)

## 原始文件位置

本目录的回归汇总转录自终端。20 步回归逐回合原件留在 4090 的 `evidence/v1/regression/v1-exec20-20261125-195734/exec20.csv`。采集验收和起点清单分别对应服务器上的 `evidence/v1/prepare.log` 与 `evidence/v1/initial-xy.csv`。采集脚本中的 50/10 是配置目标，实际帧数以这些原始文件为准。
